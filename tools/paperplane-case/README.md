# Gerador do case Paperplane Studio

Fontes que geram `sera-v1/template-parts/cases/paperplane.php`, `sera-v1/inc/paperplane-data.php` e
`sera-v1/assets/cases/paperplane/` (`node build.mjs tema <caminho-do-tema>`).

- `src/`: HTML, CSS e JS do case. `tema/en.json`: textos em inglês. `build.mjs`: o gerador.
- Os insumos do build (telas extraídas do estúdio, home embutida, microinterações, avião, mídias) não estão
  aqui por serem grandes. As versões finais deles já estão em `sera-v1/assets/cases/paperplane/`.
  Para mudanças pequenas, edite direto os arquivos gerados no tema.
- Esta pasta fica fora de `sera-v1/` e não é publicada.
